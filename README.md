# DailyTask - A Flutter Task Management App

## Description

TaskMaster is a mobile application designed to help users manage their daily tasks efficiently using Flutter. 

### Key Features:
- Create, edit, and delete tasks
- Task priority
- Task state
- User authentication
- Real-time synchronization (if implemented)

## Installation

### Prerequisites
- Flutter (version >= 3.0.0)
- Dart SDK

### Setup
1. Clone this repository:
git clone github.com/zometh/task_management

2. Navigate into the project directory:
cd task_management
3. Install dependencies:
flutter pub get
4. Run the application:
flutter run
